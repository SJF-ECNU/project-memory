关联工作流：[[project-memory/工作流/任务计划发布与本机升级]]。

## 目标与范围

按用户授权细粒度提交、推送本次任务计划书能力，并升级本机已接入 Project Memory 的项目及用户级初始化安装。保留其他未提交工作、项目特有规则、历史记录和现有工作流进度；不对未接入的项目执行新初始化，不默认替其他项目提交或推送。

## 边界与恢复

本仓库有其他任务的未提交桌面代码与导航修改，仅暂存本次差异。目标项目先读当地规则与协议，采取小范围插入；遇到正在变化的目标文件时重新读取，避免覆盖并行修改。用户级分发目录先比对，再同步权威源资产，不删除自定义文件。
