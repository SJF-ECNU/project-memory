# 每个任务绑定任务计划书

## 任务计划书

[本任务计划书](../../../../openspec/changes/bind-task-plans/design.md)，本次推进并完成 [任务清单](../../../../openspec/changes/bind-task-plans/tasks.md) 1.1–2.3。

## 目标

按用户进一步明确的要求，将服务设计参考结构用于每个后续任务的固定计划书，并让任务进度持续关联。

## 结果

本地协议、通用模板、初始化源资产和日常 Skill 已统一绑定规则。新任务实质执行前建立计划，接管按工作流→计划→最近记录读取；进度、阻塞和范围变化更新同一计划；收尾记录链接计划及当次步骤。旧任务恢复时按当前事实补建，历史不回写。

## 改动

无应用代码改动。保留开始时已有的桌面应用和其他文档未提交改动，没有发布、提交或同步用户级 Skill。
