# 每个任务绑定任务计划书

## Why

现有工作流保存目标与进度，但没有固定关联的任务计划书。用户要求把参考服务设计文档的组织方式用于每个后续任务，使目标、方案、执行步骤、验收和进度可持续接续。

## What Changes

- 提供通用任务计划书模板，保留需求、职责、执行、异常、验收和未决项的结构，并允许按任务规模裁剪。
- 新任务启动时绑定一份计划书；接管、更新进度和收尾均引用同一份计划，历史记录只追加。
- 同步仓库本地协议、模板、日常 Skill 与对外初始化资产。
- 已有 OpenSpec design.md 内容满足要求时直接复用，不复制第二份方案。

## Impact

影响文档与智能体工作流程，不修改桌面应用、插件、数据库或运行时接口。不补写已结束任务的历史计划，不部署到其他仓库或用户级 Skill。
